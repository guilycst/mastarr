## Product

- `ui/internal/config` provides a typed `Environment` snapshot and validates
  `MASTARR_UI_API_URL`, `MASTARR_UI_LISTEN_ADDR` and
  `MASTARR_UI_PUBLIC_ORIGIN` once at startup. It rejects credentials, query or
  fragment data, invalid ports, non-HTTPS public origins, controls and invalid
  listener addresses. Errors and restart guidance contain variable names and
  fixed instructions only; configured values are never logged or rendered.
- `ui/internal/client` wraps the frozen generated OpenAPI client without
  exporting generated DTOs. It reads `/health/ready` with a five-second
  per-request bound, a one-MiB response limit, rejected redirects and sanitized
  status/protocol/unavailable errors. Cancellation and deadline identity remain
  available through `errors.Is`; no upstream URL, body or transport detail is
  exposed.
- `ui/internal/shell` composes the U-00 public Goshtoso console shell and
  server-rendered content for the allowlisted dashboard routes. It emits
  configured-origin canonical, Open Graph and X/Twitter metadata, noindex and
  no-referrer directives, and displays API-ready, degraded or retriable outage
  states. Unknown paths render a private-safe shell 404; no 202 or unavailable
  response is treated as successful state.
- `ui/internal/assets` embeds the generic `preview.svg` asset as
  `image/svg+xml`, 1200x630, with accessible title/description text and no
  inventory, host, path or deployment data.
- `ui/cmd/mastarr` owns only listener lifecycle and handler assembly. It serves
  GET/HEAD shell and asset requests, rejects mutation methods, uses configured
  origin rather than Host or forwarded headers, and applies no-store,
  noindex, nosniff and no-referrer response policy to the BFF shell. It has no
  database, credential, upstream or media-mount imports.

The generated API package and `ui/go.mod`/`ui/go.sum` were frozen by U-00 and
were not changed. The UI parser therefore uses the same typed environment tags
and validation contract with a dependency-free startup snapshot; adding
`caarlos0/env/v11` or `envdoc` to the frozen UI module remains a coordinator
follow-up if an independent contract gate requires a UI-local generator. The
root generated environment reference already contains all three UI variables.
