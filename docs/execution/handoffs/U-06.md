## Delivered behavior

Added [`ui/internal/router/router.go`](../../../ui/internal/router/router.go) as
the single production route composition point. It delegates to the existing
normalized HTTP-only handlers without moving generated API DTOs or duplicating
their bounds and error classification:

- `/discoveries`, `/media`, `/downloads`, and `/descriptors` delegate to the
  inventory handler, including its list/detail identity parsing.
- `/reviews` delegates to the review handler.
- `/workflows` delegates to the workflow handler.
- `/trash` delegates to the trash handler, including detail routes and GET-only
  drafts.
- `/settings`, `/settings/connections`, `/settings/storage`, and
  `/settings/mappings` rewrite to the settings handler's existing normalized
  route vocabulary. Its native configuration, connection-check, list, and
  detail aliases remain available for handler-generated links.
- `/` and `/actions` render the configured-origin shell and readiness state.
  The current UI package set exposes no normalized action reader or action
  handler, so `/actions` is intentionally the shell overview until that
  handler is delivered by a later lane; no unowned action behavior was
  invented here.
- Unknown routes render a sanitized shell 404 without a readiness read.
- `/preview.svg`, `/assets/`, and `/consoleshell/assets/` use the local static
  handlers. Mutation methods are rejected before any delegate or API reader.

`main()` now constructs one HTTP reader for each existing normalized package
from the validated startup API origin and starts the composed router. The
legacy `NewHandler` shell-only constructor remains available for focused
startup tests and callers that intentionally provide only readiness; production
startup uses `NewHandlerWithReaders`.

The router applies GET/HEAD-only rejection and private no-store, robots,
nosniff, and referrer headers at the composition boundary. A response-writer
adapter reapplies the private policy after delegated handlers set their own
headers, while static preview assets retain their immutable public cache policy.
Readiness failures remain generic and do not reflect request Host or forwarded
host data; shell metadata uses the configured public origin.

Added synthetic end-to-end tests at
[`ui/internal/router/router_test.go`](../../../ui/internal/router/router_test.go)
cover reader route dispatch, nested settings rewrites, unknown IDs/routes,
mutation rejection, configured-origin metadata, preview asset delivery, and
sanitized outage/cancellation states.
