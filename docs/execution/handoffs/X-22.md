## Contract and work

The root Seerr adapter now delegates transport, authentication, request deadlines, bounded response decoding, pagination cursors, native DTO normalization and typed upstream errors to github.com/guilycst/mastarr/clients/seerr. The adapter owns the Mastarr translation layer only.

The root boundary retains its existing Config, Version, Capabilities, ListMedia, ListRequests, ListMediaDetailed and ListRequestsDetailed surface. It translates standalone media/request observations, page information, coverage, provider and Arr service relationships, season/request summaries, service errors, and zero-valued known manager IDs into root/domain/ports values. Public adapter types contain no generated Seerr DTOs.

Connection IDs are passed to the standalone client as its instance scope and are validated before every read. API-key, token and auth-token aliases retain the old root adapter behavior by selecting the standalone API-key transport. Standalone typed errors are normalized into sanitized Mastarr upstream errors; context cancellation and deadline identity are preserved. The adapter has no mutation method.

Synthetic fixtures are now owned under tests/fixtures/seerr/; the adapter fixture handler asserts GET-only behavior and rejects credentials other than the synthetic API key. Existing tests cover media/request pagination, overlap and drift evidence, unavailable/unsupported status, unknown native status, provider/service relationships, topology-scoped identities, malformed responses, error normalization and configured bounds.
