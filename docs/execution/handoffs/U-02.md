## Delivered scope

`ui/internal/inventory` provides a normalized, HTTP-only `Reader` boundary and
a bounded `Handler` for read-only discoveries, media catalog, downloads and
descriptor list/detail views. `HTTPReader` owns the generated-client call and
strictly validates bounded JSON before translating it into types that contain
no generated DTOs. It rejects duplicate keys, unknown fields, missing required
fields, unsafe relative paths, oversized responses, invalid cursors and
invalid detail input. Redirects are returned without following them, requests
have per-call deadlines, and cancellation/deadline identity is retained while
errors remain sanitized.

The rendered pages preserve cursor, page-size, root and connection filters,
deep-link identities, and local identity/episode/subtitle association inputs.
They show provenance, descriptor metadata, download seeding/state, coverage,
and per-instance Sonarr/Radarr/Jellyfin/Seerr tracking independently. Empty or
incomplete observations render as `unknown`; download state is not treated as
availability. Identity, episode, language, forced, SDH, pair and candidate
fields are GET-only local drafts. Every value is escaped and pages carry
private no-store/noindex headers. Descriptor content is never fetched or
embedded.

No mutations, approvals, workflow decisions, database/storage access, root
imports, upstream calls, credentials, live services or media paths were added.
The package is exposed as a handler for the later shell/router composition;
that integration remains outside this lane's owned paths.
